This page lists the packages that four features of `@luciole-sh/core` need, with the command
that installs each set. `@luciole-sh/core` declares them as optional peer dependencies, so an
app that never uses a feature does not download its packages.

| Feature                                                   | You need it when                        | Entry point                          | In the starter |
| --------------------------------------------------------- | --------------------------------------- | ------------------------------------ | -------------- |
| [Grammars](#highlight-more-languages-grammars)            | code blocks hold Bash, Python, Go…      | `import "@luciole-sh/core/grammars"` | yes            |
| [Math](#draw-display-math-math)                           | the app draws TeX formulas              | `@luciole-sh/core/math`              | yes            |
| [Web runtime](#build-for-the-browser-web-runtime)         | you build with `--web` or `--web-local` | `luciole build --web`                | no             |
| [SQLite WASM](#run-the-server-in-the-browser-sqlite-wasm) | you build with `--web-local`            | `luciole build --web-local`          | no             |

An app created with `bunx luciole.sh init` already lists the packages of grammars and math in
its `dependencies`, because the starter is the Notes example, which uses both.

## What a missing package prints

A feature whose package is missing stops with this message:

```text
<feature> needs the optional package <name>, which is not installed: run `bun add <name>`
```

- **Grammars and the web target** check their packages when you build, before bundling.
- **Math** loads its packages on the first formula, so the message shows when the app runs.

The message names only the first missing package. Install the whole set with the command of
its section below, so that the next build does not stop on the next package.
[Troubleshooting](/docs/reference/troubleshooting/#a-feature-needs-an-optional-package) gives
the same fix.

## Draw display math: math

`renderMath` from `@luciole-sh/core/math` turns TeX into a PNG, as
[the API](/docs/reference/api/#render-display-math-with-luciole-shcoremath) describes.

<CopyCommand lines={["bun add mathjax-full @resvg/resvg-wasm"]} />

| Package             | Role                     | Versions `@luciole-sh/core` accepts |
| ------------------- | ------------------------ | ----------------------------------- |
| `mathjax-full`      | turns TeX into SVG       | `^3.2.2`                            |
| `@resvg/resvg-wasm` | turns the SVG into a PNG | `^2.6.2`                            |

## Build for the browser: web runtime

`luciole build --web` bundles xterm.js into the page that draws the app in a browser.
`--web-local` implies `--web`, so it needs these packages too.
[Build and distribution](/docs/reference/build-and-distribution/) lists both flags.

<CopyCommand lines={["bun add @xterm/xterm @xterm/addon-fit @xterm/addon-webgl"]} />

| Package              | Role                               | Versions `@luciole-sh/core` accepts |
| -------------------- | ---------------------------------- | ----------------------------------- |
| `@xterm/xterm`       | draws the app's screen in the page | `^6.0.0`                            |
| `@xterm/addon-fit`   | sizes that screen to the window    | `^0.11.0`                           |
| `@xterm/addon-webgl` | draws that screen with WebGL       | `^0.19.0`                           |

## Run the Server in the browser: SQLite WASM

`luciole build --web-local` runs the Server in a browser Worker, where SQLite WASM stands in
for `bun:sqlite`. Install the web runtime's packages as well. Other builds use `bun:sqlite`
itself and do not need this package.

<CopyCommand lines={["bun add @sqlite.org/sqlite-wasm"]} />

| Package                   | Role                           | Versions `@luciole-sh/core` accepts |
| ------------------------- | ------------------------------ | ----------------------------------- |
| `@sqlite.org/sqlite-wasm` | SQLite for the Server's Worker | `^3.53.4-build1`                    |
