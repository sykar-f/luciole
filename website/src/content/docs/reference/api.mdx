This page lists what `@luciole-sh/core` exports, one export per row, under the import that
reaches it. Each heading names the entry to import from.

The framework keeps no business state. It holds no unsaved text, no pending operation and no
retry policy. It reports what happened to each request, and the app decides what to do.

## Use `@luciole-sh/core/client` in Client Components

Import this entry from Client Components only.

### Navigate between pages

These hooks are TanStack Router's own, re-exported as they are
([routing](/docs/concepts/routing/)).

| Export             | Contract                                                                |
| ------------------ | ----------------------------------------------------------------------- |
| `useNavigate()`    | Returns `navigate({ to, params?, search? })`, which opens another page. |
| `useRouter()`      | Returns the router.                                                     |
| `useRouterState()` | Returns the router's state, or the part a `select` function picks.      |
| `useParams()`      | Returns the path params of the current route.                           |
| `useSearch()`      | Returns the validated search params of the current route.               |
| `useLocation()`    | Returns the current location: its `pathname`, `search` and `hash`.      |
| `useMatchRoute()`  | Returns a function that tells whether a route matches the current page. |
| `useCanGoBack()`   | Returns `true` when the history holds an entry before the current one.  |
| `LayoutProps`      | The props of `layout.tsx`.                                              |
| `LoadingProps`     | The props of `loading.tsx`.                                             |
| `ErrorProps`       | The props of `error.tsx`.                                               |
| `NotFoundProps`    | The props of `not-found.tsx`.                                           |

### Reach the app and its connection

| Export                              | Contract                                                                                                                                         |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `useApplication()`                  | Returns the running app (members below). It throws `Missing terminal shell` outside the app's tree.                                              |
| `useConnection()`                   | Returns `{ status, error, buildError, activity, refresh }` (members below), and renders again when one of them changes.                          |
| `useInvalidation(listener)`         | Calls `listener(paths, tags)` at every invalidation, from the Server or the Client. Use it for data read outside route loaders.                  |
| `useLive(source, args, { limit }?)` | Returns `{ items, done, error }` of a generator Server Function. The subscription lasts while the component is mounted.                          |
| `TransportError`                    | A failed request. Its `outcome` is `not-sent`, `rejected` or `unknown` ([Server Functions](/docs/concepts/server-functions/#when-a-call-fails)). |
| `BuildMismatch`                     | A `TransportError` with the outcome `rejected`: the Server runs another build.                                                                   |
| `AuthenticationRequired`            | A `TransportError` with the outcome `rejected`: the request needs a signed-in user. `loginPath` is the page to sign in on, if the app has one.   |

`useLive` keeps the latest `limit` values in `items`. Default: `1000` values.

`useApplication()` returns an object with these members:

| Member                     | Contract                                                                                                                               |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `setToken(token?)`         | Replaces the token for later requests and reloads the current routes. It drops cached pages, and named fields after the first sign-in. |
| `refresh()`                | Reloads the current routes. On a failure, the page on screen stays.                                                                    |
| `invalidate(paths?)`       | Reloads the routes under `paths` and calls the `useInvalidation` listeners. Default: `["/"]`, every route.                             |
| `cancel()`                 | Goes back to the last loaded page while a navigation is pending, without a request.                                                    |
| `withSignal(signal, call)` | Runs `call`. Aborting `signal` cancels the Server Function that `call` starts, and its stream.                                         |
| `onEvent(listener)`        | Calls `listener` with each event ([events below](#observe-requests-and-navigations)). Returns the function that unsubscribes.          |
| `status`                   | The last known state of the connection (values below).                                                                                 |
| `error`                    | Why the current route could not reload. The next success clears it.                                                                    |

The first sign-in of a Client keeps the named fields, so text restored after a crash survives
it. Later calls to `setToken` clear them.

`useConnection()` returns an object with these members:

| Member       | Contract                                                                                                 |
| ------------ | -------------------------------------------------------------------------------------------------------- |
| `status`     | `Connecting`, `Connected`, `Disconnected`, `Incompatible build` or `Authentication required`.            |
| `error`      | The same value as `useApplication().error`.                                                              |
| `buildError` | In development, the last build failure. It stays until the next build succeeds.                          |
| `activity`   | `connect` before the first page, `navigate` during a navigation, `refresh` during a reload, else `idle`. |
| `refresh`    | The same function as `useApplication().refresh`.                                                         |

### Restore fields and bind keys

| Export                                    | Contract                                                                                                                                                        |
| ----------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `<Input name? value onInput />`           | OpenTUI's `input`, controlled. A `name` makes its text restorable.                                                                                              |
| `<Textarea name? value onChange />`       | OpenTUI's `textarea`, controlled. A `name` makes its text restorable.                                                                                           |
| `<ScrollBox name? …>`                     | OpenTUI's `scrollbox`. A `name` keeps its scroll position per history entry.                                                                                    |
| `useRestoredFields(group)`                | Returns `{ submit(action, { failed? }?), clear() }` for the `group/…` fields of the current history entry ([session restore](/docs/concepts/session-restore/)). |
| `useRestoredField(name, value, onChange)` | Makes a field of your own restorable. Returns the function to call with every text typed.                                                                       |
| `useRestoredFocus(names)`                 | Returns `[focus, setFocus]`: which of `names` has the focus, kept per history entry.                                                                            |
| `useBindings()`                           | OpenTUI's keymap, re-exported: adds a layer of bindings for the component's lifetime.                                                                           |
| `useActiveKeys()`                         | OpenTUI's keymap, re-exported: the bindings active now.                                                                                                         |
| `useKeymap()`                             | OpenTUI's keymap, re-exported: the keymap itself.                                                                                                               |
| `usePendingSequence()`                    | OpenTUI's keymap, re-exported: the keys typed so far of a sequence that is not complete.                                                                        |
| `<KeyHelp groups? inline? />`             | Help drawn from the active bindings that declare a `desc`, filtered by `group`.                                                                                 |

### Show other apps, terminals and Markdown

| Export                                                          | Contract                                                                                  |
| --------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| `<Embed app name active prefix? />`                             | Another luciole app in a pane ([terminals and panes](/docs/guides/terminals-and-panes/)). |
| `openApplication({ bundle, url, instance? })`                   | Loads the app that `<Embed app>` takes.                                                   |
| `<Terminal command active prefix? cwd? env? onExit? />`         | A local program on a PTY, drawn in the tree.                                              |
| `<TerminalView program label spawn active prefix? onExit? />`   | The same widget, with the host starting the program, such as a sandboxed Client.          |
| `<Markdown content streaming syntaxStyle onLink? imageBase? />` | Markdown rendered by blocks. While `content` streams, the text already shown never moves. |
| `markdownStyle(palette)`                                        | Returns a complete `SyntaxStyle` from a dozen colors (below).                             |

`<Markdown>` shows text that arrives in pieces, typically a model's answer, without flicker:

- Finished blocks render once.
- The last block is closed ahead of time, so `**bold` shows bold.
- Text is styled without Tree-sitter, so the streaming and final renders match.
- Code is coloured once its fence closes, and `diff` blocks line by line from the start.
- A click on a link calls `onLink(url)`.
- Images are drawn with kitty, sixel or half blocks.

OpenTUI colours JavaScript, TypeScript, Markdown and Zig. Import `@luciole-sh/core/grammars`
once, in the Client, to add Bash, C, C++, CSS, Go, HTML, Java, JSON, Lua, PHP, Python, Ruby,
Rust, TOML and YAML. That import also replaces OpenTUI's TypeScript grammar, and gives TSX a
grammar of its own.

`markdownStyle({ text, muted, faint, accent, onBand, band, bandQuiet, code, panel, link,
danger, ok })` derives every group `<Markdown>` reads from those colors:

- H1 and H2 on `band`, H3 on `bandQuiet`
- code blocks on `panel`
- the Tree-sitter groups of the grammars above

`@luciole-sh/markdown-editor` reads the same groups, so a note looks the same read and
written.

### Ask the host for a capability

```tsx
import { CapabilityDenied, host, useCapability } from "@luciole-sh/core/client";

await host.clipboard.write(path); // rejects with CapabilityDenied if the host refuses
const state = useCapability("clipboard.write"); // "granted" | "denied" | "prompt"
```

| Export                          | Contract                                                                              |
| ------------------------------- | ------------------------------------------------------------------------------------- |
| `host.clipboard.read()`         | Resolves with the clipboard's text.                                                   |
| `host.clipboard.write(text)`    | Writes `text` to the clipboard.                                                       |
| `host.notify({ title, body? })` | Shows a system notification.                                                          |
| `host.openUrl(url)`             | Opens `url` in the browser. Only `http` and `https` URLs are accepted.                |
| `host.secret(name)`             | Resolves with the origin's keychain entry `name`, or `undefined` when it is absent.   |
| `host.tabs.post(message)`       | Sends `message` to the app's other tabs.                                              |
| `host.tabs.onMessage(fn)`       | Calls `fn(message, from)` for each message from another tab. Returns the unsubscribe. |
| `host.input.onGlobalKey(fn)`    | Calls `fn` for each global key. Returns the unsubscribe.                              |
| `CapabilityDenied`              | The error each `host` call rejects with when the host refuses.                        |
| `useHostMessage(fn)`            | `host.tabs.onMessage(fn)` while the component is mounted.                             |
| `useGlobalKey(key, fn)`         | Calls `fn` on the global key `key` while the component is mounted.                    |
| `useCapability(name)`           | Returns the capability's state: `granted`, `denied` or `prompt`.                      |

Who answers depends on how the Client runs:

- A standalone Client or an `inline` pane acts itself, with the user's rights. It runs the
  system's tools, such as `pbcopy`, `xdg-open` or `security`, and every capability is
  `granted`.
- A `sandbox` Client asks its host
  ([apps you did not write](/docs/guides/untrusted-apps/#who-enforces-what)).

### Observe requests and navigations

| Export                           | Contract                                                                                                                       |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `<DebugOverlay limit? />`        | Shows requests, open requests, bytes, the last round trip and the latest `limit` events since it mounted. Default: `6` events. |
| `instrumentTracing(app, tracer)` | Opens one span per request on an OpenTelemetry `Tracer`, or a compatible one. Returns the function that stops.                 |

`useApplication().onEvent(listener)` receives these events. Every event carries `at`, in
epoch milliseconds.

| `type`       | When                                        | Fields                                                 |
| ------------ | ------------------------------------------- | ------------------------------------------------------ |
| `request`    | A request leaves.                           | `callId`, `kind`, `target`, `cause`                    |
| `response`   | The response's status arrives.              | `callId`, `kind`, `target`, `status`, `ms`             |
| `chunk`      | A chunk of the body arrives.                | `callId`, `kind`, `target`, `bytes`                    |
| `end`        | The body ends or is cancelled.              | `callId`, `kind`, `target`, `ms`, `bytes`, `cancelled` |
| `error`      | The request fails.                          | `callId`, `kind`, `target`, `ms`, `outcome`, `message` |
| `navigation` | A navigation resolves.                      | `path`                                                 |
| `invalidate` | The Server or the Client declares a change. | `paths`, `tags`, `origin`                              |
| `loader`     | A page loader starts or ends.               | `phase`, `routeId`, `href`, `cause`, `source`          |
| `failure`    | A page fails to load or render.             | `path`, `message`                                      |

- `callId` is the ID the Server reads with `getCallId()`.
- `cause` is `navigation`, `preload`, `refresh`, `invalidation`, `action`, `live` or
  `unknown`.
- `notFound()` does not emit a `failure`.
- Listeners run on the hot path. Keep them light, and never let them throw.

| Export                                     | Contract                                                                                           |
| ------------------------------------------ | -------------------------------------------------------------------------------------------------- |

| `Shell({ app })`                           | Renders an `Application`.                                                                          |
| `run(create, { name?, sessionKey? })`      | Starts a Client in the current process. Its options are `RunOptions`.                              |

| `ApplicationEvent`                         | The type of the events above.                                                                      |
| `LiveState`, `TracerLike`                  | The types of `useLive`'s result and of `instrumentTracing`'s tracer.                               |

## Use `@luciole-sh/core/server` on the Server

| Export                                   | Contract                                                                                                                       |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `getSession()`                           | Returns `{ userId }`, the sign-in session of the current render or Server Function call.                                       |
| `getOptionalSession()`                   | Returns the sign-in session, or `null` for an anonymous request. A public page or Server Function gets a signed-in user's too. |
| `getCallId()`                            | Returns the transport request's ID, distinct from the business operation.                                                      |
| `getArgs()`                              | Returns the app's arguments, untyped ([app arguments](/docs/reference/app-arguments/)).                                        |
| `getLaunch()`                            | Returns the launch: `{ scope, id?, cwd }`.                                                                                     |
| `notFound(what?)`                        | Ends a page's render with the nearest `not-found.tsx`.                                                                         |
| `invalidate(path?)`                      | Declares, from a Server Function, that the data under `path` changed. Default: `"/"`, every route.                             |
| `invalidate({ tag })`                    | Drops the cached results labelled `tag`. Resolves once they are gone ([caching](/docs/concepts/cache/)).                       |
| `cacheLife()`, `cacheTag()`              | Set the age and the tags of a `"use cache"` result.                                                                            |
| `memoryCache()`, `sqliteCache({ path })` | The two cache stores. Their types are `CacheHandler`, `CacheEntry` and `CacheEvent`.                                           |
| `AuthConfig`                             | The type of `server/auth.ts`'s default export ([authentication](/docs/concepts/authentication/)).                              |
| `createHandler(config, options)`         | The Server as a function of a `Request`, without listening.                                                                    |
| `serve(config)`                          | `createHandler` on `Bun.serve`, with the environment, the socket and the lifetime.                                             |

These calls throw an `Error` with these messages:

| Call                                   | Message                                                                     | When                                                         |
| -------------------------------------- | --------------------------------------------------------------------------- | ------------------------------------------------------------ |
| `getSession()`, `getOptionalSession()` | `No request session`                                                        | Called outside a render or a Server Function call.           |
| `getSession()`                         | `Authentication required`                                                   | The request has no signed-in user.                           |
| `invalidate(path)`                     | `invalidate(path) is only available in Server Functions: no Client to tell` | Called outside a Server Function call.                       |
| `invalidate(path)`                     | `invalidate() takes an absolute path`                                       | `path` does not start with `/`, or is over 1,000 characters. |

[Server Functions](/docs/concepts/server-functions/#declare-what-a-server-function-changed)
explains when to call `invalidate`.

`serve({ instrument })` hands `instrument.onEvent(event)` two kinds of events:

- a `ServerEvent` for every `/render` and `/action`: `request`, `response`, `end` or `error`,
  with `callId`, `kind`, `target` and `at`
- each `CacheEvent` of the cache

Without `instrument`, no response is wrapped. `/action` answers with
`Server-Timing: total;dur=…`.

## Render display math with `@luciole-sh/core/math`

```ts
import { renderMath } from "@luciole-sh/core/math";

const png = await renderMath("e^{i\\pi} + 1 = 0", { display: true, color: "#e6e6e6", scale: 8 });
```

`renderMath(tex, { display, color, scale })` returns a `Promise<Uint8Array>`:

- a PNG of `tex` on a transparent background, in `color`
- at `scale` pixels per `ex`
- in display math when `display` is `true`, else inline math

It rejects TeX that MathJax cannot read.

Pass it to the `math` option of `@luciole-sh/markdown-editor` to draw display math in
terminals that draw pictures, as Notes does.

The entry is opt-in, like `grammars`. Its two optional peer dependencies, `mathjax-full` and
`@resvg/resvg-wasm`, weigh a few megabytes. Install them in your app. They load on the first
formula.

## Supervising an app: `@luciole-sh/core/dev`

These exports are what `luciole dev` is made of. A host uses them to supervise an app while it
decides itself when to rebuild, as studio does at the end of a model's turn.

| Export                                  | Contract                                                                                             |
| --------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `startAppServer(options)`               | Starts a built app's Server. Resolves `{ port, child, stop }` once the Server prints its ready line. |
| `bearerRelay()`                         | Returns `{ attach(client) }`, which hands the token from one Client to the next in memory.           |
| `serialize(task)`                       | Returns `{ run, busy }`, which never runs `task` twice at once.                                      |
| `onClientFailure(client, listener)`     | Calls `listener` with each `ClientFailure` a Client sends its parent.                                |
| `ClientFailure`                         | The schema of `{ type: "failure", path, message }`.                                                  |
| `linkFrameworkModules(directory, from)` | Links `.luciole/node_modules` to the framework's packages.                                           |
| `stopChild(child)`                      | Stops a child with SIGTERM, then SIGKILL after 1.5 s.                                                |

`startAppServer` takes these options:

| Option       | Contract                                                                        |
| ------------ | ------------------------------------------------------------------------------- |
| `directory`  | The app's directory. Its `.luciole/server/index.js` is started.                 |
| `output?`    | The output directory, when the app was built elsewhere.                         |
| `env`        | The Server's whole environment, `PORT` included.                                |
| `command?`   | Wraps the argv, to start the Server confined.                                   |
| `onOutput?`  | Receives each line of stdout that is not the ready line.                        |
| `stderr?`    | `inherit`, or a function that receives the Server's stderr. Default: `inherit`. |
| `timeoutMs?` | How long to wait for the ready line. Default: `10000` ms.                       |

`startAppServer` rejects with `Server exited before ready` or `Server startup timeout`. When
`stderr` is a function, the message ends with the last lines of the Server's stderr.

A rebuild keeps the user signed in: `bearerRelay` passes the token on, never through a file.
With `serialize`, calls made during a run ask for one more run after it.

A Client started with an IPC channel sends its parent every page failure:
`{ type: "failure", path, message }`. `luciole dev`, a `sandbox` host and studio start it that
way. The message is cut to 2,000 characters. The error screen tells a person, and this message
tells the program that started the Client which page failed and why.

## Replace or wrap the transport

The transport is a replaceable interface. Inject one with `createApplication({ transport })`,
or decorate the default one with `createApplication({ wrapTransport })`, without touching the
runtime. `wrapTransport(inner)` returns the transport to use. A cache, a recorder or a replay
is a decorator.

<Excerpt

  find="export interface Transport"
  until="^}"
  tone="wire"
/>

The default adapter, `createHttpTransport`, carries:

- the build header and the token
- the timeout, which bounds the wait for the root of an answer. Default: `10000` ms.
- the simulated latency
- typed errors and events
- invalidation and progressive Flight decoding

A decorator sees every `render` and `call`. What it throws reaches the app as it is, so it
must let each `TransportError` and its `outcome` through.

<Note>
  The packages are published on npm, at version 0.x. A patch release does not break the API, and a
  minor release may. The changelog lists each break, and the [status page](/status/) says what is
  stable enough to rely on.
</Note>
