The framework holds no business state: no Draft, no pending operation, no retry policy. It
reports what happened to each request; the app decides.

## `@luciole-sh/core/client`

For Client Components only.

### Navigation

| Export                                                                                                                                 | Contract                                                                             |
| -------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| `useNavigate()`, `useRouter()`, `useRouterState()`, `useParams()`, `useSearch()`, `useLocation()`, `useMatchRoute()`, `useCanGoBack()` | TanStack Router's own, re-exported as they are ([routing](/docs/concepts/routing/)). |
| `LayoutProps`, `LoadingProps`, `ErrorProps`, `NotFoundProps`                                                                           | Props of `layout.tsx`, `loading.tsx`, `error.tsx` and `not-found.tsx`.               |

### The app and its connection

| Export                                                      | Contract                                                                                                                                                      |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `useApplication()`                                          | `{ setToken(token?), refresh(), invalidate(paths?), cancel(), withSignal(signal, call), onEvent(listener), status, error }`.                                  |
| `useConnection()`                                           | `{ status, error, buildError, activity, refresh }` for the chrome; `activity` is `connect`, `navigate`, `refresh` or `idle`.                                  |
| `useInvalidation(listener)`                                 | Called at every invalidation, from the Server or the Client, with the paths and tags: for data read outside route loaders.                                    |
| `useLive(source, args, { limit }?)`                         | `{ items, done, error }` of a generator Server Function, subscribed while the component is mounted; `items` keeps the last `limit` values (1,000 by default). |
| `TransportError`, `BuildMismatch`, `AuthenticationRequired` | Typed failures; `outcome` is `not-sent`, `rejected` or `unknown` ([Server Functions](/docs/concepts/server-functions/#when-a-call-fails)).                    |

### Fields and keys

| Export                                                                    | Contract                                                                                                                                                |
| ------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `<Input name? value onInput />`, `<Textarea name? value onChange />`      | OpenTUI's `input` and `textarea`, controlled; a `name` makes their text restorable.                                                                     |
| `useRestoredFields(group)`                                                | `{ submit(action, { failed? }?), clear() }` for the `group/…` fields of the current history entry ([session restore](/docs/concepts/session-restore/)). |
| `useRestoredField(name, value, onChange)`                                 | A field of the app's own made restorable: returns the function to call with every text typed.                                                           |
| `useRestoredFocus(names)`                                                 | `[focus, setFocus]`: which of `names` has the focus, kept per history entry.                                                                            |
| `<ScrollBox name? …>`                                                     | OpenTUI's `scrollbox`; a `name` keeps its scroll position per history entry.                                                                            |
| `useBindings()`, `useActiveKeys()`, `useKeymap()`, `usePendingSequence()` | OpenTUI's keymap, re-exported: layers of bindings tied to components' lifetimes.                                                                        |
| `<KeyHelp groups? inline? />`                                             | Help drawn from the active bindings that declare a `desc`, filtered by `group`.                                                                         |

### Panes, terminals, Markdown

| Export                                                                             | Contract                                                                                  |
| ---------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| `<Embed app name active prefix? />`, `openApplication({ bundle, url, instance? })` | Another luciole app in a pane ([terminals and panes](/docs/guides/terminals-and-panes/)). |
| `<Terminal command active prefix? cwd? env? onExit? />`                            | A local program on a PTY, drawn in the tree.                                              |
| `<TerminalView program label spawn active prefix? onExit? />`                      | The same widget, the host starting the program itself: a sandboxed Client, a custom stop. |
| `<Markdown content streaming syntaxStyle onLink? imageBase? />`                    | Markdown rendered by blocks: while `content` streams, the text already shown never moves. |
| `markdownStyle(palette)`                                                           | A complete `SyntaxStyle` (heading bands, code panel, code tokens) from a dozen colors.    |

`<Markdown>` shows text that arrives in pieces, typically a model's answer, without flicker.
Finished blocks render once. The last block is closed ahead of time, so `**bold` shows bold.
Text is styled without Tree-sitter, so the streaming and final renders match.

Code is coloured once its fence closes, and `diff` blocks line by line from the start. A click
on a link calls `onLink(url)`. Images are drawn with kitty, sixel or half blocks.

OpenTUI colours JavaScript, TypeScript, Markdown and Zig. Import `@luciole-sh/core/grammars`
once, in the Client, to add Bash, C, C++, CSS, Go, HTML, Java, JSON, Lua, PHP, Python, Ruby,
Rust, TOML and YAML. That import also replaces OpenTUI's TypeScript grammar, and gives TSX a
grammar of its own.

`markdownStyle({ text, muted, faint, accent, onBand, band, bandQuiet, code, panel, link,
danger, ok })` derives every group `<Markdown>` reads from those colors: H1 and H2 on
`band`, H3 on `bandQuiet`, code blocks on `panel`, and the Tree-sitter groups of the
grammars above. `@luciole-sh/markdown-editor` reads the same groups, so a note looks the same read and
written.

### Asking the host

| Export                                                               | Contract                                                                                                |
| -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| `host`, `CapabilityDenied`                                           | What the app asks its host for: clipboard, notification, URL, secret, tabs.                             |
| `useHostMessage(fn)`, `useGlobalKey(key, fn)`, `useCapability(name)` | Messages from other tabs and global keys while mounted; a capability's `granted`, `denied` or `prompt`. |

```tsx
import { CapabilityDenied, host, useCapability } from "@luciole-sh/core/client";

await host.clipboard.write(path); // rejects with CapabilityDenied if the host refuses
const state = useCapability("clipboard.write"); // "granted" | "denied" | "prompt"
```

`host.clipboard.read()` / `.write(text)`, `host.notify({ title, body? })`, `host.openUrl(url)`
(http(s) only), `host.secret(name)` (the origin's keychain entry, `undefined` if absent),
`host.tabs.post(message)` / `.onMessage(fn)`, `host.input.onGlobalKey(fn)`. A standalone
Client or an `inline` pane acts itself, with the user's rights (`pbcopy`, `osascript`,
`open`, `security`), and everything is `granted`; a `sandbox` Client asks its host
([apps you did not write](/docs/guides/untrusted-apps/#who-enforces-what)).

### Observing

| Export                           | Contract                                                                                                       |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| `<DebugOverlay limit? />`        | Requests, open requests, bytes, last round trip and the latest `limit` events (6 by default) since it mounted. |
| `instrumentTracing(app, tracer)` | One span per request to an OpenTelemetry `Tracer` (or a compatible one); returns the stop function.            |

`useApplication().onEvent(listener)` receives each transport event (`request`, `response`,
`chunk`, `end`, `error` with its `outcome`) and each resolved navigation, plus `invalidate`
(`paths`, `tags`, `origin`), `loader` (`phase`, `routeId`, `source`…) and `failure` (`path`,
`message`: a page failed to load or render; not emitted for `notFound()`). Every event carries
`at`, in epoch milliseconds; transport events carry the `callId` sent to the Server and a
`cause` (`navigation`, `preload`, `refresh`, `invalidation`, `action`, `live`, else
`unknown`). Listeners run on the hot path: keep them light.

### For hosts and generated code

`Application` (from `createApplication(options)`), `ApplicationOptions`, `ApplicationEvent`,
`Shell({ app })`, `run(create, { name?, sessionKey? })` and `RunOptions`, `createActions()`,
and the types `LiveState`, `TracerLike`, `Session`, `SessionEntry`,
`OpenApplicationOptions`, `PublisherCheck`. An app does not need them.

## `@luciole-sh/core/server`

| Export                                                                | Contract                                                                                                                                               |
| --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `getSession()`                                                        | `{ userId }` in the async context of a render or an action.                                                                                            |
| `getOptionalSession()`                                                | The request's session, or `null` for an anonymous request; a public page or Server Function gets a signed-in user's session too.                       |
| `getCallId()`                                                         | The transport request's ID, distinct from the business operation.                                                                                      |
| `getArgs()`, `getLaunch()`                                            | The app's arguments, untyped; the launch `{ scope, id?, cwd }` ([app arguments](/docs/reference/app-arguments/)).                                      |
| `notFound(what?)`                                                     | Ends a page's render with the nearest `not-found.tsx`.                                                                                                 |
| `invalidate(path?)`, `invalidate({ tag })`                            | Declares what changed ([Server Functions](/docs/concepts/server-functions/#declare-what-a-server-function-changed), [caching](/docs/concepts/cache/)). |
| `cacheLife()`, `cacheTag()`, `memoryCache()`, `sqliteCache({ path })` | The `"use cache"` cache, and the types `CacheHandler`, `CacheEntry`, `CacheEvent`.                                                                     |
| `AuthConfig`                                                          | The type of `server/auth.ts`'s default export ([authentication](/docs/concepts/authentication/)).                                                      |
| `createHandler(config, options)`                                      | The Server as a function of a `Request`, without listening.                                                                                            |
| `serve(config)`                                                       | `createHandler` on `Bun.serve`, with the environment, the socket and the lifetime.                                                                     |

`serve({ instrument })` hands `instrument.onEvent(event)` a `ServerEvent` for every
`/render` and `/action` (`request`, `response`, `end`, `error`, with `callId`, `kind`,
`target` and `at`) and the cache's `CacheEvent`s. Without `instrument`, no response is
wrapped. `/action` answers with `Server-Timing: total;dur=…`.

## Display math: `@luciole-sh/core/math`

```ts
import { renderMath } from "@luciole-sh/core/math";

const png = await renderMath("e^{i\\pi} + 1 = 0", { display: true, color: "#e6e6e6", scale: 8 });
```

`renderMath(tex, { display, color, scale })` returns a `Promise<Uint8Array>`: a PNG of `tex`
on a transparent background, in `color`, at `scale` pixels per `ex`. `display` chooses display
or inline math. It rejects TeX that MathJax cannot read.

Pass it to the `math` option of `@luciole-sh/markdown-editor` to draw display math in
terminals that draw pictures, as Notes does.

The entry is opt-in, like `grammars`. Its two optional peer dependencies, `mathjax-full` and
`@resvg/resvg-wasm`, weigh a few megabytes: install them in your app. They load on the first
formula.

## Supervising an app: `@luciole-sh/core/dev`

What `luciole dev` is made of, for a host that supervises an app but decides itself when to
rebuild (studio, at the end of a model's turn):

| Export                                                                                  | Contract                                                                                                                                                                                                                                                              |
| --------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `startAppServer({ directory, output?, env, command?, onOutput?, stderr?, timeoutMs? })` | Starts a built app's Server and resolves `{ port, child, stop }` once it prints its ready line (10 s by default). If it exits or times out first, it rejects, with the end of its stderr when `stderr` is a function. `command` wraps the argv, to start it confined. |
| `bearerRelay()`                                                                         | `{ attach(client) }`: hands the bearer from one Client to the next in memory, so a rebuild does not ask to sign in again.                                                                                                                                             |
| `serialize(task)`                                                                       | `{ run, busy }`: never two runs at once; calls during a run ask for one more after it.                                                                                                                                                                                |
| `onClientFailure(client, listener)`, `ClientFailure`                                    | The `{ type: "failure", path, message }` messages a Client sends its parent.                                                                                                                                                                                          |
| `linkFrameworkModules(directory, from)`, `stopChild(child)`                             | Links `.luciole/node_modules` to the framework's packages; stops a child with SIGTERM, then SIGKILL.                                                                                                                                                                  |

A Client started with an IPC channel (by `luciole dev`, a `sandbox` host, studio) sends its
parent every page failure: `{ type: "failure", path, message }`, the message cut to 2,000
characters. The error screen alone only tells a person; this tells the program that started
the Client which page failed and why.

## The transport

The transport is a replaceable interface, injected with `createApplication({ transport })`,
or decorated with `wrapTransport(inner)` (a cache, a recorder, a replay) without touching the
runtime:

<Excerpt

  until="^}"

/>

The default adapter, `createHttpTransport`, carries the build header, the bearer, the timeout
(10 s by default, bounding the wait for the root of an answer), the simulated latency, typed errors, events, invalidation
and progressive Flight decoding. A decorator sees every `render` and `call`; what it throws
reaches the app as it is, so it must let `TransportError`s and their `outcome` through.

<Note>
  The packages are published on npm, at version 0.x. A patch release does not break the API, and a
  minor release may. The changelog lists each break, and the [status page](/status/) says what is
  stable enough to rely on.
</Note>
