# Ce que la landing a rendu à la documentation

La landing v2 ne garde que ce qui donne envie d'essayer. Le contenu ci-dessous en est
sorti ; il revient dans la documentation anglaise (`/docs/`, sources dans
`src/content/docs/`). Chaque composant se retrouve dans sa dernière version au commit
**`e157896`** (base de la refonte) :

```sh
git show e157896:website/src/components/Toolbox.astro
```

État au 27 septembre 2026 (phase 1 de la documentation) : tout le contenu est couvert
en texte ; trois éléments **visuels ou interactifs** sont reportés, faute d'un composant
de documentation qui les porte sans recopier ceux de la landing.
