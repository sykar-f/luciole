# luciole.sh

The install name of [luciole](https://luciole.sh): React Server Components in your terminal.

```sh
bunx luciole.sh init
bun add -g luciole.sh
```

This package only provides the `luciole` command and hands every argument to
[`@luciole-sh/core`](https://www.npmjs.com/package/@luciole-sh/core), which is the framework. Bun only.
